# References

Layout reviewed on 2026-10-26.

- [postmarketOS deviceinfo](https://docs.postmarketos.org/pmaports/main/deviceinfo-reference.html): device metadata alongside distribution packages.
- [Droidian adaptation packages](https://docs.droidian.org/porting-guide/rootfs-creation/): device configuration packaged separately from the base system.
- [Arch Linux on Xiaomi Pad 6S Pro](https://github.com/code002-2/archlinux-sheng): pacman packages, patches and image scripts.
- [Surface Duo Droidian port](https://github.com/agentsco-lab/surfaceduo-droidian): separate adaptation, kernel packaging and device documentation.

This project uses those organizational patterns. It does not use the
Droidian/Halium runtime or claim compatibility with those devices.
